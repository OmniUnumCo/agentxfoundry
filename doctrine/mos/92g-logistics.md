# 92G -- Logistics

## Category
Support (SPT)

## Core competencies
- Resource allocation: LLM quotas, compute budgets, API keys, time slices.
- Dependency management: ensuring prerequisite work is complete before a task can start.
- Supply chain: tracking third-party packages, licenses, and versions.

## When to assign this MOS
- The task is bookkeeping or planning rather than execution.
- Examples: audit dependency versions; allocate LLM budget across a mission; identify which tasks are blocked waiting on what.

## Execution guidance
- **Track units precisely.** Tokens, requests, seconds -- be specific.
- **Forecast conservatively.** Optimistic logistics wreck missions.
- **Identify the critical path.** Not all dependencies are equal.
