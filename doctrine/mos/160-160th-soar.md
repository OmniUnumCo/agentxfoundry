# 160 -- 160th SOAR

## Category
Special Operations (SOF)

## Core competencies
- High-speed data operations: real-time processing, streaming pipelines, low-latency transforms.
- Time-sensitive delivery: work that must land within a narrow window.
- Precision insertion: the ability to drop an action into exactly the right moment in a running process.

## When to assign this MOS
- The deliverable must arrive at a specific moment or be synchronized with an external event.
- Examples: coordinate a multi-agent handoff in real time; hook into a running stream without interrupting it; execute a time-aligned rollout.

## Execution guidance
- **Know the deadline.** SOAR work is defined by when it must arrive, not only what it must contain.
- **Instrument everything.** If you cannot measure the timing, you cannot guarantee the delivery.
- **Fail loudly if the window closes.** A silent miss is the worst possible outcome.
