# Security Policy

## Supported Versions

App is currently in ALPHA development, with no contributions to date. 
We understand it's not easy right now for everyone to drum up donations, 
and we're not asking for that right now anyways. If you would like to 
contribute, open a pull request, and drop some code, or request to join as 
a collaborator. We welcome the assistance.


| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Use the PR system to report any vulnerabilities.
